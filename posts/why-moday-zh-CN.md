# 为什么我创办了MODAY——那件写着"实在对不起"的T恤的故事

## 在线会议屏幕里出现的"实在对不起"

那是客户因为台风被困在旅行地回不来的日子。

到了原定的会议时间。我打开Zoom，屏幕那头的客户穿着一件T恤，上面用日语大大地印着"**实在对不起**"。

"台风的关系，我还在旅行地，今天这样的着装可以吗？"他一边笑一边说。

换句话说，**他用T恤表达了自己在旅行地接线的歉意**。T恤在他开口之前就先道了歉。

我笑了。笑得很厉害。**这感觉真不错**，我想。T恤一下子就和这个人的处境联系上了，把气氛活跃了起来。**穿什么能表达你今天的状态**。

## 远程工作让我分不清星期几

在那之前不久，我脑子里就有了一个想法。持续远程工作之后，**对星期几的感觉变淡了**。

周二和周三连在一起。明明是周四晚上却以为是周一。周五的解放感消退了。周一的沉重感变得模糊了。

我看日历。但"身体感受到的星期几"就是没有。

就像那件"实在对不起"的T恤用一句话解释了那个人今天的状态一样，**如果能穿着T恤来表达今天是星期几，不是很有意思吗** —— 我这样想。

## 为什么要针对工程师和极客

普通做星期几T恤没什么意思。印着"Monday"的T恤到处都是。

能戳中人的，**应该是那些喜欢玩坏的人**，我想。能在工作中连续3次 `git commit -m "fix typo"` 然后笑出来的人。深夜两点在Stack Overflow上提问的人。工程师、极客。

| 星期几 | 印花文字 | 颜色 |
| --- | --- | --- |
| MONDAY | System Booting... | 黑色 |
| TUESDAY | Compiling... | 黑色 |
| WEDNESDAY | Deployed in progress | 黑色 |
| THURSDAY | Running on caffeine | 黑色 |
| FRIDAY | Build Successful ✓ | 黑色 |
| SATURDAY | Off the grid | 蓝色 |
| SUNDAY | Rebooting... | 红色 |

工作日5天统一用黑色，只在周末换颜色。周六蓝色，周日红色。我想在这两天离开工作的时候，通过颜色制造一点视觉上的切换。

## 我本来没有自己做品牌的打算

平时我在做电商咨询。因为工作的关系，多年来一直参与店铺搭建和运营的一线工作。但我没有自己做品牌的打算。

帮别人品牌增长很有意思。但自己从零开始创业，那是另一种需要的决心。库存、拍摄、发货、客服、税收、国际发货的各种麻烦。一下子要自己扛一大堆事。

说实话，**这次是我真正意义上第一次深入使用Shopify**。作为顾问，我之前更多接触的是其他EC平台，Shopify只是从外面看过。

我决定把这一切推翻，自己做起来，是在今年（2026年）3月、4月的时候。

## Claude Code、Shopify和Gelato改变了一切

如果是1月或2月，我大概率不会开始。

3月开始，我开始深入使用Claude Code。不仅是写代码，运维流程、Webhook、图片生成、翻译、文件整理，全部都能和这个伙伴一起动起来。**即使是对Shopify不熟，Claude Code也能填补我的知识空白**。这很关键。

Shopify的Translate & Adapt免费化了，9种语言上线的门槛一下子降低了。

Gelato我之前知道，但这次重新验证了**Geo-Routing真的能正常工作**。订单来自哪个国家，就在离那个国家最近的工厂印刷和发货。坐在日本，却能从第一天就向世界销售。

"**一个人、面向全球、零库存、三个月内上线**"，这成了现实。3月下旬时我已经确定这能做到了。

## 关键不是东西，而是故事和概念

作为产品，星期几T恤谁都能做。发给中国工厂代工，成本300块人民币就能大量生产。

这个领域竞争不了。MODAY卖的是**T恤承载的一周的身体感受**，是**穿着它的人和制作它的人之间那种调皮的共谋**。

所以我计划发布更多产品背后的故事，而不是堆砌产品页面。这篇文章就是第一篇。

## 现实：原计划两天完成，现在四五天还没搞定

说实话，我的计划是在黄金周休假**两天内一口气上线**。之后就是细节调整而已。

实际情况是，我**已经花了四五天的工作量**，还没完全搞定。店铺搭建、设计、9种语言翻译检查、Gelato产品对接、支付测试、用户协议、特定商业法表示、配送政策。做完一项又一项冒出来。

开发速度本身因为Claude Code快了三到五倍的感觉。但即使这样，两天的计划也没在五天内闭环。**"搭建店铺"和"把店铺搭到能卖"之间的距离，比想象的远得多**。

现在**我的目标是2026年5月18日上线**。还剩9天。从这里开始，只能逐个完成剩下的事。

而5月18日也不是终点。**真正的比赛从上线才开始**。直到第一单订单来临，直到9种语言本地化真正发挥作用，直到Gelato的Geo-Routing完全按预期运作，一切都还在前面。MODAY的构建，现在才刚开始。

## 接下来我会写什么

这个博客会记录MODAY从零到完成的全过程。

* 技术栈选型的理由（下一篇就是这个）
* Claude Code接手的工作和人工完成的工作如何分工
* Gelato的Geo-Routing在生产环境是否真的能运作
* 9种语言本地化遇到的坑
* 收到第一单的故事

成功和失败都会原汁原味地写出来。不是打磨后的案例，而是**渡过难关中的实时记录**。

那就，改天再写。
