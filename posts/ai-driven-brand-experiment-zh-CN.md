# 连 AI 都拿不走的四件事

我在做 MODAY——一个一个人运营的"周一到周日"T 恤品牌，并且在尝试把每一件具体的事都交给 AI 去做。三天过去了，有四件事就是不肯走。

## 我为什么在做这个实验

为什么做这个品牌，比较表面的那一半已经写过：日本那件印着"对不起"的 T 恤当年很出圈、远程办公会让工作日的界限模糊。这些算是面子上的话。

更难说出口的另一半是这个——**我想搞清楚 AI 时代怎么造一家公司，而且想比别人更早搞清楚。**

主业是做电商咨询，业务现场看得不少。从生成式 AI 真正起来的这两三年开始，有一个问题一直卡在脑子里没走过：**到底能让 AI 把一门生意开到多深？**

读新闻、刷 Twitter、看论文，都给不出答案。这其实合理——这种问题不是靠"读"能读出来的。**它只在一门真有钱在流的真生意面前，才会让步。**

所以 MODAY 同时是一个 T 恤品牌，也是 **一个适合用来测量的一人实验场**。零库存，一人运营，第一天就全球上线，三天发布完成。真金白银在动，真的客户在买，真的包裹在发。兴趣项目或者公司内部测试，判断会松。**没有真实的紧张感，量不出来任何东西。**

规则只有一条：不划界限。能交的全部交出去。然后看哪些不动。

## 三天下来，零后悔

"这块我不该让 AI 做"的那一刻，到目前为止一次都没发生。技术栈选型也没有。设计也没有。店铺搭建、Webhook、翻译、文案，一个也没有。Claude 输出的东西，我几乎都原样上线了。

听起来像在炫耀。其实不是。更诚实的解读更黯淡——**我连自己的判断标准都一起交给 Claude 了**，所以我心里根本找不到一个可以挂"后悔"的着力点。如果我守着自己的判断不放，迟早会出现一个"等一下，我本来想走的方向不是这个"的瞬间。这个瞬间没出现。

好的层面也好，坏的层面也好，都没出现。

## 然而——有四件事就是没走

虽然嘴上说"不划界限"，实际搭建过程中，有四块拒绝被交出去。用减法列一下：

**1. "要不要发提示词"这件事本身。**

发给 Claude 的第一句话——"接下来做什么？"——一直是我自己打。每一次。我消不掉它。

如果这一步也能交出去，应该就到下一个阶段了。我还没到。

**2. 银行账户和支付审核。**

Shopify Payments 审核。Stripe 实名认证。开通跨境收款账户。这里只有人能进去。带着证件出现，用自己的名字和脸签字，成为合同当事人。

**3. 各服务的注册与绑定信用卡。**

Gelato、Render、fal.ai、Make.com、Anthropic。每一个，都要我创建账号、绑信用卡、升级到付费方案。每一次注册都是我自己的手在控制台里点。

**4. 生成 API 密钥——直到把它交出去那一刻为止。**

为了让 Claude Code 能调 API，密钥必须先存在。"创建新密钥"这个按钮是我按的。密钥一进入 `.env`，从那一刻起，它就不再是我的了。

这就是完整名单。三天的搭建里，我的手实际上动过的地方就这四块。其余的，全都是 Claude 在跑。

## 第一件事，我也想放手

四件里，**我最想脱手的就是第 1 件——"要不要发提示词"这件事本身。**

理想形态：Claude Code 主动来找我说"接下来该做的是这个"，我只回 OK 或 NG，**生意本身的方向，整个搬到 AI 那一侧。**

技术上估计现在就能做。用 agent 式的结构搭一遍，Claude Code 可以自己切任务、自己实现、再提出下一个任务，形成闭环。已经有人在跑这种东西。

但 MODAY 现在的阶段，我还没走到那一步。我心里还有一块，想自己决定第一步走哪个方向。说实话，问题就在这一块。**把这一块放掉，是我的下一步。**

## 剩下三件不是"AI 的极限"，是"制度的极限"

这一段是我这篇文章最想写的部分。

银行、KYC、注册、支付绑定、API 密钥——它们留在人这一侧，**不是因为"AI 缺乏相应的判断力"**。不是这个原因。

真正的原因是制度性的。**AI 没有法律人格。** 既不是自然人，也不是法人。无法成为合同的当事人。仅此而已。

技术上看，给 Claude Code 加上浏览器自动化能力，明天就让它去做这些事，估计是可以的。填表单、上传证件照片、点开邮件里的验证链接。Computer Use 已经存在，挡在前面的不是能力。

挡在前面的是——**就算 Claude 点完了那些点击，登记的当事人依然是我。** Claude 只是在用我的名字填表，责任仍然由人类承担。

所以这三件不是"AI 触及的边界"，而是 **"社会制度还没追上的领域"**。等到 AI 自己能在法律意义上成为业务主体那一天，这三件也会一起搬过去。

## 不是分工，是减法

"人做什么、AI 做什么"这种划分，三年后大概会显得过时。

一旦你画下那条线——"人在这里、AI 在那里"——这条线就会变成约束。**"AI 究竟能走多远"这个问题，在这条约束之内，是没法回答的。** 你不能去测量一条自己提前定好的边界。

所以 MODAY 不是分工。而是 **把所有事都先交出去，再用减法去检查哪些没能走**。

留下的四件里，三件是制度性的，一件是我自己的主动性。

时间会解决那三件。剩下那一件——只能我自己放手。

回头再聊。

— Yoskee
